# Reference Design Databases

Standalone, reusable UI/UX design databases stored alongside the primary `skills/ui-ux-pro-max/` engine.

## Available Databases

- **[polygon-uiux-db](polygon-uiux-db/README.md)** (`Dark Kinetic Emerald`): Relational SQLite (`polygon_uiux.db`), ANSI SQL dump (`polygon_uiux.sql`), W3C-style tokens (`tokens/design-tokens.json`, `tokens/polygon-theme.tokens.css`), and 11 CSV/JSON exports covering `14` reusable page templates, `12` section blocks, `14` components, `6` button archetypes, `21` GSAP/CSS motion specs, and `8` accessibility/performance audit remediations — with **zero company data**.
